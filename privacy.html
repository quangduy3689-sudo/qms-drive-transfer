Privacy Policy

QMS Drive Transfer · Last updated: November 6, 2026

Purpose

QMS Drive Transfer is a personal utility that uses rclone and the Google Drive API to retrieve ZIP archives from a designated Google Drive account to the owner's Ubuntu computer for local processing.

Google user data accessed

The application requests the Google Drive read-only scope (drive.readonly). It may access file names, metadata, and file content needed to locate and download ZIP archives. It does not request permission to create, modify, or delete files in Google Drive.

How data is used and stored

Downloaded files are saved to the owner's local Ubuntu computer and processed in a local workflow. OAuth credentials are stored locally in rclone's configuration for authenticated access. This public website does not receive uploaded files, Google Drive content, or OAuth credentials.

Sharing and third parties

The application does not sell Google user data, use it for advertising, or transmit downloaded Google Drive content to this website. Google Drive is the source of the downloaded data. Local downstream processing is managed by the owner.

Retention and deletion

The owner controls downloaded files and can delete local copies at any time. Access can be revoked from the Google Account's third-party connections settings; the local rclone configuration can also be removed.

Security

Access uses Google's OAuth authorization flow and is restricted to the owner's computer and Google account. The owner is responsible for protecting their local device and credentials.

Contact

For questions about this personal application, contact the repository owner through the GitHub repository.
