QMS Drive Transfer

A private file-transfer utility for a personal video-production workflow.

What the application does

QMS Drive Transfer uses Google Drive API access through rclone to download ZIP archives from a designated Google Drive account to a user's own Ubuntu computer. The archives are used as inputs for a local video-production workflow.

Access requested

The application requests read-only Google Drive access. It can list and download files but does not require permission to edit or delete files in Google Drive.

Who uses this application?

This application is intended for personal use by its owner. It is not a public file-sharing service and does not offer user accounts.
